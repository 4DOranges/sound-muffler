# Sound Muffler

## A RuneScape 3 plugin
Mute all the annoying sounds!

Features:
* Premade groups of sounds that may annoy people, like all the Smithing sounds or every Moan, Groan and other such mouth-noises
* The ability to mute individual sounds & search for them by ID or name
* Preview each sound, if you want, so you know you're muting the right one
* See all your muted sounds in one place
